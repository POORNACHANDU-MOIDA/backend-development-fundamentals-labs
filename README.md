## Repository Structure

The repository organizes each practical lab into its own dedicated folder alongside a shared root `.gitignore`:

```text
backend-development-fundamentals-labs/
├── .gitignore
├── README.md
├── lab-01/
├── lab-02/
...
└── lab-10/
```

- Each lab directory contains its own source code, dependencies, documentation, and output screenshots.
- The root `.gitignore` prevents `node_modules/`, environment configuration files (`.env`), and logs from being committed to version control.

## How to Run a Lab

To run any lab on your local machine:

1. Navigate into the desired lab directory:
   ```bash
   cd lab-01
   ```
2. Install the necessary packages:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```
